# Archived legacy tools

Files in this directory are historical utilities, not part of the active
Minecraft 26.3 Fabric source set.

`MainPerformanceTest.java` comes from an older Minecraft API generation.
It references legacy packages and `FixedEntityLookHelper`, which is not part
of the current 26.3 implementation. It is retained for historical reference
only and is not compiled or executed by the Fabric build.
